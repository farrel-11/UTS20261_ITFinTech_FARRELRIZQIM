## 🛠️ Tech Stack
- Next.js 16 (Pages Router)
- React 19
- Tailwind CSS v4
- MongoDB Atlas + Mongoose
- Xendit Payment Gateway (Test Mode)
- Deployed on Vercel

## 📱 Pages
1. **Select Item** - Menu display with 15 products from MongoDB
2. **Checkout** - Cart summary with server-side calculation
3. **Payment** - Method selection, integrated with Xendit
4. **Success** - Auto-updated status via Xendit webhook
